# WRTE public pages

Marketing: https://ezhu331.github.io/wrte-app/
Support: https://ezhu331.github.io/wrte-app/support/

Static HTML, CSS and a local slideshow of actual app screenshots. Weather and restaurant information reflect capture time. Screenshots contain no account details and PNG metadata is stripped. No location permissions, analytics, cookies, storage or network requests. GitHub Pages serves main over HTTPS. Reduced-motion preferences disable effects and automatic playback.
